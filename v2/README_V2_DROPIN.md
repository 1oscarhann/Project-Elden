# How to use this folder

Merge this "v2" folder straight into your repo root — everything's already placed where it
needs to go:

- docs/ROADMAP_V2.md                        → merges into your existing docs/
- docs/phases/phase11_hunger_thirst.md      → merges into your existing docs/phases/
- docs/phases/phase02_world.md              → OVERWRITES existing (has terrain/density updates)
- raw_assets_v2/                            → new folder, holding v2 art not wired in yet

After merging, delete this README_V2_DROPIN.md (or leave it, doesn't matter).

First prompt to run:
"Read docs/phases/phase11_hunger_thirst.md in full, then follow it and build it. Follow CLAUDE.md."
